# 📊 Social Media Data Analytics Project

## 📌 Project Overview

This project focuses on analyzing Instagram user activity and engagement data using SQL and MySQL to generate meaningful business insights for marketing, user engagement, and growth strategies.

The analysis explores user behavior, content performance, engagement patterns, and retention trends to understand how social media platforms can improve user experience and make data-driven decisions.

## 🎯 Project Objectives

- Analyze Instagram user behavior and engagement patterns.
- Identify highly active users and popular content.
- Discover trending hashtags and content performance.
- Analyze user retention and acquisition trends.
- Generate actionable insights for improving engagement.
- Support data-driven marketing and business decisions.

## 🗂️ Dataset Information

The project uses an Instagram-style relational database containing the following tables:

- **Users** – User registration and profile information.
- **Photos** – Information about uploaded photos.
- **Likes** – User engagement through likes.
- **Comments** – User comments and interactions.
- **Follows** – Relationships between users.
- **Tags** – Hashtag information.
- **Photo_Tags** – Relationship between photos and hashtags.
